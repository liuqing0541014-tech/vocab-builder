# 生词本 · 闪卡学习

一个纯前端实现的英文生词本应用，支持PDF上传、自动提取生词、闪卡学习、艾宾浩斯间隔复习。

## 功能

- **PDF 上传解析** — 使用 PDF.js 提取文本
- **高频词提取** — 自动分词、词频统计、过滤停用词、简单词形还原
- **单词难度分级** — 基于词频和词长自动标记初/中/高
- **闪卡学习** — 正面英文 + 图片，背面中文释义 + 原文例句
- **TTS 发音** — 浏览器内置语音合成
- **艾宾浩斯复习** — 间隔重复算法，自动安排复习时间
- **每日学习量设置** — 可自定义每日新词和复习上限
- **词库导入/导出** — JSON 格式备份
- **配图** — 自动从 Unsplash 获取关键词图片

## 使用

直接用浏览器打开 `index.html` 即可，无需服务器。

```bash
# 或者起个本地服务器
npx serve .
```

## 技术栈

- 纯 HTML/CSS/JS，无框架
- PDF.js（CDN）解析 PDF
- MyMemory 翻译 API（免费）
- Web Speech API 发音
- localStorage 本地存储

## 文件

- `index.html` — 完整单文件应用（含所有 CSS/JS）
